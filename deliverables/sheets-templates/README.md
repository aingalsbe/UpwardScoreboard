# Sheets templates

Import order: courts.csv, then teams.csv, then schedule.csv (Admin > Import / Export).

Keep the id column when you edit the schedule. Download the schedule export, edit it in Google Sheets and re-import it with the id column still there. The id is how a game whose time, court or teams changed gets updated instead of added a second time. Leave id blank only for brand-new games, and do not reuse or retype ids.

Courts: the gym has one floor, used either as Full (slug full) or split into West (west) and East (east). West and East run at the same time; Full can't overlap either of them. In courts.csv, conflicts_with lists the courts a court can't overlap (full has "west east"). Leave the column empty for the half courts.

minutes (optional) is the game length. Leave it empty to use the default (GAME_MINUTES, 60). A Full game whose start time + length overlaps a West or East game (or the other way round) is reported as a row error naming the other game. Back-to-back is fine: a West game 10:00-11:00 then Full at 11:00.

A game that is not scheduled yet can have date and time both empty (court may be empty too).

Team names are unique within a grade: 2nd Grade Eagles and 5th Grade Eagles are two teams (see teams.csv). teams.csv matches on grade + name. In schedule.csv, fill the grade column when a team name exists in more than one grade; without it, a name used in one grade only is found automatically, and a name in several grades takes the other team's grade, otherwise the row is an error.

home_score and away_score are used only with status complete. status is optional: a game that never started can be set to complete with its scores; other status changes are made in Admin.

Uploaded cheer logos are exported as the full address of the served file; re-importing keeps the upload.

Full column reference: section 10 of ../UpwardScoreboard-POC.md.

Partial rows: a row with only id and status (and home_score/away_score for complete) changes just that game's status; the other columns can be blank or left out. Clearing a cheer logo cell removes the game's uploaded logo. A cheer logo address that points to another game's uploaded logo (for example after copying a row) is not carried over; the row imports with a warning, so upload the logo for the new game in Admin.

## Gender, example weekend and warnings (2026-10)

teams.csv and schedule.csv have a gender column: Boys or Girls (b/g, boy/girl also accepted). Team names are unique per grade + gender + name, so 3rd Grade Boys Eagles and 3rd Grade Girls Eagles can both exist. A game must be within one grade and one gender; schedule.csv's gender column picks the right team when a name exists in both.

The example files are the demo weekend (generated by `node scripts/gen-templates.mjs [friday]` from the same plan as the demo seed): Friday Full Court 17:30, 18:30, 19:30; Saturday West + East hourly 08:00–15:00 (2nd grade 08–10, 3rd 11–13, 4th 14–15, one Boys and one Girls game per slot), then Full Court 16:30, 17:30, 18:30 (5th–6th grade). Every team plays exactly once. Cheer squads only on some Saturday split games.

Import also reports warnings (the rows still import): a team playing twice in one Fri–Sat weekend; a cheer squad on a game that isn't 2nd–4th grade or isn't a Saturday West/East game between 08:00 and 16:00; a West/East game that starts before 08:00 or ends after 16:00. Admin > Schedule lists the same warnings.
