Import / Export (Google Sheets compatible CSV)

Teams

Columns: name, short_name, grade, gender, coach, logo_url (coach: first name, optional) (gender: Boys or Girls; names are unique per grade + gender). Existing names are updated. Old files with color columns still import; the colors are ignored (season colors apply).

Export teams.csv

Courts

Columns: slug, name, location, conflicts_with (optional; e.g. west east for the full court). Upserted by slug. Import courts before the schedule; scorekeeper PINs stay in COURT_PINS.

Export courts.csv

Schedule

Columns: id, date (YYYY-MM-DD), time (HH:MM), court (slug), division, home, away, optional grade, gender, minutes, swap_colors, home_locker, away_locker. Older files with cheer / cheer_logo (or home_cheer/away_cheer) still import: the squad is set for that game's hour. Keep the id column when editing an export. Times are league-local (TZ). Unknown courts and teams are rejected. Games must be on a Friday or Saturday with tip-off 8 AM–9 PM league time (8:00–21:00): rows that break this are rejected with their row number and reason. status=complete marks a row as a final (a finished game, e.g. restoring an export; it needs home_score and away_score): finals are exempt from the game-hours rule and import with a warning only. A Full game can't overlap a West or East game; a game can't overlap another on the same court or a game of either team (finals restored from a file don't block each other). Export adds home_score, away_score and status; on import, status=complete with both scores records the final result.

Cheer squads

Columns: name, coach, optional logo. Matched by name. Import before cheer slots.

Cheer slots

Columns: date, time, squad, locker. One squad per hour (all courts); matched by date + hour. A blank squad removes the cheer for that hour.
