Import / Export (Google Sheets compatible CSV)

Teams

Columns: name, short_name, grade, logo_url. Existing names are updated. Old files with color columns still import; the colors are ignored (season colors apply).

Export teams.csv

Courts

Columns: slug, name, location, conflicts_with (optional; e.g. west east for the full court). Upserted by slug. Import courts before the schedule; scorekeeper PINs stay in COURT_PINS.

Export courts.csv

Schedule

Columns: id, date (YYYY-MM-DD), time (HH:MM), court (slug), division, home, away, optional grade, minutes, swap_colors, home_cheer, home_cheer_logo, away_cheer, away_cheer_logo. Keep the id column when editing an export. Times are league-local (TZ). Unknown courts and teams are rejected. A Full game can't overlap a West or East game. Export adds home_score, away_score, status (ignored on import).

Export schedule.csv

In Google Sheets: File → Download → CSV to import here; File → Import → Upload to load an export.
