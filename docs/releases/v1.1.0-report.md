## 4. Deviations & Open Questions

- **Deviations:**
  1. `GET /api/practice/clock` and `POST /api/practice/clock/{pause,resume,restart}` include an additive `serverNow` field alongside `{practice}` / `{ok, practice, tvs}` so the Admin UI ticks accurately against server time even under `SCOREBOARD_TEST_CLOCK`.
  2. `test/release2-practice-clock.test.ts` pre-seeds each scratch DB via `seed-demo.js` (instead of `SEED:'true'`, which in `src/db.ts` only calls `seedIfEmpty()` without populating `practice_days`/`practice_slots`) so test-clock servers have the full Mon–Thu demo practice schedule and boot cleanly before boundary transitions.
  3. Throwaway Postgres used locally cached `postgres:16-alpine` (matching the repo's `Dockerfile`/`SETUP.md`) on port `55442`, and was removed afterward.
- **Open questions:** None — all specs and §8 decisions were unambiguous and implemented as specified.
